# Tellbook for ChatGPT — private beta

This package connects an authenticated Tellbook provider to their own service catalog. It supports reading services and setup choices, creating and editing drafts, duplicating services, organizing sections, changing visibility, explicitly publishing or pausing, and deleting when dependency rules permit. Booking management, payments, business setup changes, and image uploads are outside this release.

Remote endpoint: `https://api.tellbook.app/mcp/chatgpt`. Tellbook sign-in and consent: https://tellbook.app. Connect an authorized Tellbook provider account and choose its catalog permissions. No credentials are included in this archive. These addresses target the production server; the earlier isolated beta validation does not establish production availability.

Enable ChatGPT developer mode in Settings → Security and login. On Plugins, use Add → Create custom MCP server, enter the remote endpoint above, choose OAuth, and connect Tellbook. This connection flow was tested against the isolated beta; verify the production endpoint after deployment. The portable package adds the Tellbook workflow skill for private repo or local marketplace installation.

From the server repository, run `python3 scripts/package-integrations.py` to build both portable packages with the production API and app origins. For another deployment, supply both `--api-origin https://your-api.example` and `--client-origin https://your-app.example`; use `--output-dir` to keep its archives separate. Endpoint, author, website, and README URLs are updated together in the archives; source files are not changed by packaging.

For a workspace package that reuses an existing registration, additionally supply `--chatgpt-server-id plugin_asdk_app_YOUR_REGISTERED_ID`. The registration must point at the intended production endpoint; a beta registration retains its beta connection even if the package website changes. This produces a separate workspace archive with `extensions.com.openai.apps` pointing to `.app.json`; the server ID is normalized to its `asdk_app_` identity. It contains no duplicate direct MCP configuration. Registrations belong to the account/workspace that created them; supply your own ID for another workspace. The ordinary portable archive contains the remote URL and no account-specific mapping.

Choose the permissions you need on the Tellbook consent screen. Read access is included; edit, publish/pause, and delete are separate opt-ins. Disconnect immediately in Tellbook Settings → Connected apps. Password or account security changes invalidate existing grants. Logging out of Tellbook alone leaves a granted connection active.

Choose all permissions you expect to use during the initial connection to avoid separate reconnections for each category. Unchecked permissions remain unavailable. Access tokens refresh automatically within the 30-day connection; routine authorized edits do not require reconnecting. ChatGPT's per-app permission preference can reduce action prompts to important changes, subject to workspace policy ([permission controls](https://developers.openai.com/plugins/changelog#app-permission-controls-in-chatgpt)). These prompts are separate from Tellbook consent.

Try: “List my Tellbook services”; “Create a draft 45-minute virtual consultation for NGN 2500”; “Move my draft consultation to a new section”; “Pause Business consultation.” Start from a read and use returned IDs and revisions. All mutation retries must retain the same idempotency key and unchanged arguments.

Installation guidance: [official documentation](https://developers.openai.com/plugins/build/plugins). Public directory submission has not been made. Legal policy URLs, developer contact, registered host identity, real-host recordings, and submission approval must be supplied or verified before public submission. See `docs/operations/provider-integrations.md` and `docs/review/provider-integrations.md` in the server repository.
