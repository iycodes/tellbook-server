# Tellbook for Claude — private beta

This package connects an authenticated Tellbook provider to their own service catalog. It supports reading services and setup choices, creating and editing drafts, duplicating services, organizing sections, changing visibility, explicitly publishing or pausing, and deleting when dependency rules permit. Booking management, payments, business setup changes, and image uploads are outside this release.

Remote endpoint: `https://api.tellbook.app/mcp/claude`. Tellbook sign-in and consent: https://tellbook.app. Connect an authorized Tellbook provider account and choose its catalog permissions. No credentials are included in this archive. These addresses target the production server; the earlier isolated beta validation does not establish production availability.

From the server repository, run `python3 scripts/package-integrations.py` to build both portable packages with the production API and app origins. For another deployment, supply both `--api-origin https://your-api.example` and `--client-origin https://your-app.example`; use `--output-dir` to keep its archives separate. Endpoint, author, website, and README URLs are updated together in the archives; source files are not changed by packaging.

Use the archive in `plugins/dist` with Customize → Plugins → Add → Upload plugin. Open the installed plugin’s Connectors tab and connect Tellbook using OAuth. You can also use Customize → Connectors → Add custom connector, enter the remote endpoint above, and select Claude’s published OAuth identity. This connection flow was tested against the isolated beta; verify the production endpoint after deployment. Its exact client metadata URL is `https://claude.ai/oauth/mcp-oauth-client-metadata`; configure this identity on the production server as well. Other clients are rejected. For Claude Code, use `claude --plugin-dir ./plugins/claude` and `/mcp`; Code requires separately authorized client identities and is outside this hosted-chat beta.

Choose the permissions you need on the Tellbook consent screen. Read access is included; edit, publish/pause, and delete are separate opt-ins. Disconnect immediately in Tellbook Settings → Connected apps. Password or account security changes invalidate existing grants. Logging out of Tellbook alone leaves a granted connection active.

Choose all permissions you expect to use during the initial connection to avoid separate reconnections for each category. Unchecked permissions remain unavailable. Access tokens refresh automatically within the 30-day connection; routine authorized edits do not require reconnecting. In Customize → Connectors → Tellbook → Tool permissions, review the available Always allow, Needs approval, and Blocked choices for individual tools or categories. Availability depends on account/workspace policy ([connector controls](https://support.claude.com/en/articles/11176164-use-connectors-to-extend-claude-s-capabilities)). Read tools are annotated read-only; mutations retain Claude's required destructive annotations and can still require host approval.

Try: “List my Tellbook services”; “Create a draft 45-minute virtual consultation for NGN 2500”; “Move my draft consultation to a new section”; “Pause Business consultation.” Start from a read and use returned IDs and revisions. All mutation retries must retain the same idempotency key and unchanged arguments.

Installation guidance: [official documentation](https://claude.com/docs/plugins/build). Public directory submission has not been made. Legal policy URLs, developer contact, registered host identity, real-host recordings, and submission approval must be supplied or verified before public submission. See `docs/operations/provider-integrations.md` and `docs/review/provider-integrations.md` in the server repository.
